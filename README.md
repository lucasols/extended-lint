# extended-lint

Monorepo for the `@ls-stack/extended-lint` ESLint plugin and its native type-aware linter.

## Packages

- [`@ls-stack/extended-lint`](./packages/extended-lint) - custom ESLint rules for TypeScript/JavaScript projects
- [`@ls-stack/fast-lint`](./packages/fast-lint) - the type-aware rules running natively on tsrs (Rust), without ESLint
